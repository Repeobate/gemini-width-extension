# Gemini 宽屏宽度调节（Gemini Width Controller）

一款轻量级、零闪烁的 Edge / Chrome 浏览器扩展（Manifest V3），用于自由调节 Google Gemini 网页版（`https://gemini.google.com`）的显示宽度与沉浸阅读体验。

## 主要功能

- **自由调节回答宽度**：支持 **40% 至 100%** 实时滑块调节与快捷档位（60% / 75% / 85% / 95%），纯静态 CSS 驱动，流式输出 0 闪烁、滚动 0 抖动。
- **全区域对齐**：对话正文、标题、列表、代码块、表格、思考过程块、底部操作栏与输入框统一对齐；空白首页自动保持原生居中。
- **表格优化**：
  - 支持 **表格文字居中**（水平与垂直居中）。
  - 支持 **表格列宽按字数智能分配**：简短列紧凑显示，长文本说明列自动分配更宽空间，减少行数落差。
- **沉浸阅读自动隐藏**：
  - **底部输入框自动隐藏**：阅读对话时自动收起到底部，鼠标移到底部细线处平滑弹出；打字聚焦或打开下拉菜单时保持显示，按 `Esc` 可快速收起。
  - **左侧缩略栏自动隐藏**：左侧栏处于缩略窄条状态时自动向左隐藏，鼠标移到最左边缘平滑悬浮弹出；展开完整侧边栏查看历史会话或设置时自动常驻。

## 安装方法（Edge / Chrome）

1. 下载或克隆本仓库到本地文件夹。
2. 打开浏览器扩展管理页面：
   - Edge：`edge://extensions/`
   - Chrome：`chrome://extensions/`
3. 开启 **开发人员模式**。
4. 点击 **加载解压缩的扩展**，选择本仓库根目录。
5. 打开或刷新 [Google Gemini](https://gemini.google.com/)，点击浏览器右上角扩展图标即可实时调节。

## 权限说明

- `storage`：仅用于在本地保存你的宽度与开关偏好设置。
- `tabs` / `scripting`：仅用于在你点击插件图标时向已打开的 `gemini.google.com` 标签页实时同步配置，不收集或上传任何数据。

## 更新日志

### v1.1.0
- **彻底修复表格流式生成期间跳动问题**：
  - 宽屏模式下对表格默认启用纯静态 CSS `table-layout: fixed`，消除 Gemini 流式重建 `<table>` 时原生 `table-layout: auto` 引起的列宽震荡。
  - 移除往 `<table>` 内部插入 `<colgroup>` 的做法，改为独立 `<style>` 纯 CSS 规则控制列宽，避免与 Angular DOM 更新冲突。
  - 流式输出期间完全不介入动态列宽计算；待整轮回答彻底生成完毕且页面静止 1.2 秒后，统一按表格完整内容一次性智能对齐列宽。

### v1.0.0
- 首个正式发布版本：支持 40% 至 100% 宽度调节、全区域对齐、表格居中与智能列宽、底部输入框与左侧缩略栏自动隐藏。
